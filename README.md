# GZNodes for ComfyUI

[English | [中文](./README.cn.md)]

## Introduction

Various custom nodes for `ComfyUI`.

`ComfyUI` offical page: [https://registry.comfy.org/nodes/comfyui-gznodes](https://registry.comfy.org/nodes/comfyui-gznodes)

## Command-line installation

Installation command:

```bash
comfy node install comfyui-gznodes
```

## Manual installation

1. Clone this repo into `custom_nodes` folder of `ComfyUI`.

```bash
cd {Your_ComfyUI_Folder}/custom_nodes
git clone https://github.com/shines77/ComfyUI-GZNodes
```

2. Install dependencies: `pip install -r requirements.txt`
   or if you use the portable install `ComfyUI`, run this in `ComfyUI_windows_portable` folder:

```bash
python_embeded\python.exe -m pip install -r ComfyUI\custom_nodes\ComfyUI-KJNodes\requirements.txt
```
