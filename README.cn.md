# GZNodes for ComfyUI

[[English](./README.md) | 中文]

## 简介

`ComfyUI` 的各种自定义节点。

`ComfyUI` 官方页面: [https://registry.comfy.org/nodes/comfyui-gznodes]()

## 命令行安装

安装命令：

```bash
comfy node install comfyui-gznodes
```

## 手动安装

1. 将此仓库克隆到 `ComfyUI` 的  `custom_nodes` 文件夹中。

```bash
cd {Your_ComfyUI_Folder}/custom_nodes
git clone https://github.com/shines77/ComfyUI-GZNodes
```

2. 安装依赖项：`pip install -r requirements.txt`，
   或者，如果您的 `ComfyUI` 使用的是绿色安装，请在 `ComfyUI_windows_portable` 文件夹中运行此程序：

```bash
python_embeded\python.exe -m pip install -r ComfyUI\custom_nodes\ComfyUI-KJNodes\requirements.txt
```
